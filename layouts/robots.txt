Policy: search engines are welcome; AI training and scraping crawlers are not.
Search visibility is unaffected — Googlebot, Bingbot and Applebot are never
named here, so they fall through to the permissive "*" group. The two
training-only opt-outs (Google-Extended, Applebot-Extended) are separate
user-agents from their search crawlers, so blocking them costs no indexing.

Assistant "user" agents (ChatGPT-User, Claude-User, Perplexity-User) fetch a
page because a reader asked an assistant to read it, rather than to build a
training set. They are blocked here too, deliberately — drop those three lines
if you would rather let readers pull posts into an assistant.

robots.txt is advisory: it stops the operators who honour it, and nothing else.
Enforcement would need a proxy in front of Netlify, which this site deliberately
does not have (see the Cloudflare DNS-only setup).

Crawlers match the MOST SPECIFIC user-agent group, so each block below fully
replaces the "*" group for that agent — no need to repeat the sitemap in them.

Note: the non-production branch below never fires on this site — hugo.yaml pins
params.env to "production", so the condition is always true (that is the theme's
own behaviour, not something this override introduced). It is kept so the guard
works if that param is ever unpinned. Deploy previews therefore serve this same
file.

Re-check against the theme copy after npm run theme:update. */ -}}
